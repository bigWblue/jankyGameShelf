# Tic-Tac-Toe

<img width="405" height="406" alt="ticTacToeSShot" src="https://github.com/user-attachments/assets/c781e054-2714-42cd-8013-d5a0ed62fc5f" />

A version of tic-tac-toe to play on the computer or mobile browser.

## How to play
+ Default mode is single player, uncheck the box if you want to pick every move.
+ Click/tap on any square to place your symbol
+ Whoever makes a straight line of 3 increases their points
+ After filling every square, click on any square to play again while keeping the scores
+ To start from zero, click the Reset button
